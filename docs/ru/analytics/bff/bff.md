# {heading(Сервис BFF)[id=bff_service]}

Сервис BFF — предназначен для управления процессом создания облачных ресурсов на {var(sys2)} на уровне бэкенда.

## {heading(Просмотр задач)[id=bff_job]}

Задача — объект для отслеживания данных процесса создания облачных ресурсов {var(sys2)}:

* Инстанса ВМ.
* Файлового хранилища.
* Сети.
* Инстанса БД.

Задача запускается в момент создания ресурса {var(sys2)} в Портале самообслуживания.

Чтобы посмотреть задачи в Портале администратора: 

1. Перейдите в раздел **BFF** → **Задачи**. 
1. При необходимости установите критерии поиска задачи. 
1. Нажмите на название задачи, чтобы просмотреть информацию по процессу создания ресурса:
 
   * Тайминг. 
   * Логи. 
   * Шаги выполнения задачи и их параметры. 
   * Данные запроса, по которому запущен процесс создания компонента.
   * Ошибки и описание по ним, в случае их возникновения при создании.

## {heading(Просмотр воркеров)[id=bff_worker]}

Воркер — объект, который выполняет задачи. 

Чтобы посмотреть список воркеров в Портале администратора:

1. Перейдите в раздел **BFF** → **Воркеры**. 

   <info>

   В списке воркеров доступны данные о том, сколько задач выполняет и выполнил каждый воркер, какие задачи выполнились с ошибкой.

   </info>

1. При необходимости установите флаг **Только активные**. 

1. Нажмите на название воркера, чтобы получить его расширенные данные:

   * Время запуска.
   * Время обновления.
   * Данные запроса на запуск.
