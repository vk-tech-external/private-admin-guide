# {heading(Основные интерфейсы)[id=arch-interfaces]}

Для работы с {var(sys5)} используются следующие типы интерфейсов:

* Графические интерфейсы (GUI).
{ifdef(box)}
* Командные строки (CLI).
{/ifdef}
* Программные интерфейсы (API).

Далее будут рассмотрены основные интерфейсы, доступные для взаимодействия со стороны пользователей и администраторов {var(sys2)}.

## {heading(Графические интерфейсы)[id=arch_graphical_interfaces]}

Чтобы получить доступ к функциям Портала администратора или Портала самообслуживания необходимо пройти двухфакторную аутентификацию. Для двухфакторной аутентификации используется пароль учётной записи и код, приходящий по электронной почте.

Чтобы открыть графический интерфейс {var(sys2)}:

1. При помощи веб-браузера перейдите по адресу Портала администратора или Портала самообслуживания.
1. Введите логин и пароль учётной записи от соответствующего Портала.
1. Нажмите кнопку **Войти** или **Войти в личный кабинет**. На электронную почту, которая используется в качестве логина, придет письмо с кодом.
1. Введите код из письма и нажмите кнопку **Войти** или **Войти в личный кабинет**.

При успешной двухфакторной аутентификации откроется интерфейс Портала администратора или Портала самообслуживания.

### {heading(Портал самообслуживания)[id=arch_graphical_interfaces_mcs]}

<!--- //MCS UI / VK CP UI -->

Портал самообслуживания является основным графическим интерфейсом пользователей {var(sys2)} и используется для управления виртуальными ресурсами в рамках одного или нескольких проектов. Каждая учётная запись может иметь доступ к неограниченному количеству проектов. Роли пользователей, а значит и их доступ к функциям {var(sys2)} могут отличаться от проекта к проекту.

{ifndef(cer)}
Условное обозначение: VK CP UI (или MCS UI, устаревшее).
{/ifndef}

Доступ к Порталу самообслуживания {var(sys2)} осуществляется при помощи веб-браузера по адресу:

<!--- //формат записи взят из черновика техпаспорта эталонного стенда https://docs.google.com/spreadsheets/d/140oP1VeiEH1dLY0vQHCPeTrJisP4Uqakig8WuxuXHtM/edit#gid=0 (здесь и далее) -->

```txt
vkc.your_domain_name.ru
```

где `your_domain_name.ru` — это доменное имя Заказчика {var(sys2)}.

Для входа в Портал самообслуживания используется любая персональная учётная запись пользователя {var(sys2)}.

### {heading(Портал мониторинга)[id=arch_graphical_interfaces_mon]}

### {heading(Портал управления доступом)[id=arch_graphical_interfaces_manage_control]}

Портал управления доступом является графическим интерфейсом администраторов {var(sys2)} для управления пользователями, группами пользователей и настройками защиты отдельных сервисов {var(sys2)}.

Через этот интерфейс или через API Keycloak создаются, удаляются и настраиваются стандартные учетные записи {var(sys2)}. А также задаются различные параметры доступа к {var(sys3)}, например, интеграция {var(sys2)} с LDAP-провайдером в части учётных записей пользователей.

```txt
idm.your_domain_name.ru
```

где `your_domain_name.ru` — это доменное имя Заказчика {var(sys2)}.

Для входа в Портал управления доступом используется стандартная учётная запись {var(sys2)}, имеющая соответствующие права доступа.

## {heading(Интерфейсы командной строки)[id=arch_graphical_interfaces_command_line_interfaces]}

Для работы Пользователей {var(sys2)} использование командной строки не требуется.

Для администрирования {var(sys2)} может потребоваться использование следующих интерфейсов командной строки:

* SSH и Bash (выполнение команд после подключения к узлам {var(sys2)}).
* OpenStack CLI.
* Ansible.
* cURL.

<warn>

При расследовании инцидентов возможно потребуется дополнительно использовать следующие интерфейсы командной строки:

* Docker CLI.
* Kubectl.

</warn>

{/ifdef}

Защищённый протокол для удалённого доступа к компьютерам, в том числе для подключения к узлам {var(sys2)}.

{caption(Команда для подключения к узлу {var(sys2)})[align=left;position=above]}
```console
$ ssh <ИМЯ_ПОЛЬЗОВАТЕЛЯ>@<IP_ХОСТА>
```
{/caption}
