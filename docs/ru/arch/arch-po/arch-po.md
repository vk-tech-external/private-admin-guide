# {heading(Программное обеспечение)[id=arch-po]}

{var(sys1_go)} — программный комплекс на базе программного обеспечения с открытым исходным кодом (OpenStack и др.) и программного обеспечения собственной разработки.

Для функционирования {var(sys2_go)} необходимо вспомогательное ПО, не входящее напрямую в состав {var(sys2_go)}.

Программные компоненты {var(sys2_go)} размещаются на серверах, разделенных на логические группы — серверные роли, в зависимости от выполняемых функций. Часть компонентов {var(sys2_go)} размещена на виртуальных серверах.
