# {heading(Основные решения по обеспечению отказоустойчивости)[id=arch-reliability]}

Архитектура {var(sys2)} обеспечивает надежность (отказоустойчивость) {var(sys2)}, включая поддержание штатного режима работы при выходе из строя отдельных узлов аппаратного обеспечения и/или программных компонентов {var(sys2)}.

В случае размещения серверов контура управления в трех доменах отказа, при выходе из строя одного домена отказа (полностью или частично) сохраняется полноценное функционирование контура управления.

Основные способы обеспечения надежности {var(sys2)}:

* Компоненты {var(sys2)}, размещенные на управляющих узлах, объединяются в кластеры высокой доступности (High Availability) с балансировкой нагрузки.
* Возможно добавление нового вычислительного узла в кластер виртуализации без остановки и перебоев в функционировании {var(sys2)}.
* Вывод вычислительного узла из эксплуатации и освобождение от нагрузки не приводят к перебоям в функционировании {var(sys2)}.
