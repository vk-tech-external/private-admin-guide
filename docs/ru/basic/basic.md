# {heading(Общая информация)[id=basic]}

<info>

Перед изучением **Руководства администратора {var(system)}** рекомендуем ознакомиться с составом, структурой и функциональными возможностями программного комплекса, приведенными в **Описании {var(system)}**.

</info>

{var(system)} — это программный комплекс, предназначенный для построения частной облачной инфраструктуры с каталогом услуг, устанавливаемый на аппаратные мощности, предоставляемые Заказчиком в собственном ЦОДе (On-premises).

В состав {var(sys2)} входят следующие функциональные компоненты:

{ifndef(cer)}
* Интерфейсы:

   * Подсистема потребителя облачных услуг.
   * Подсистема администрирования.

* Общие подсистемы:

   * Подсистема тарификации и биллинга.
   * Подсистема служебных хранилищ.

* Группа подсистем IaaS:

   * Подсистема вычислительных ресурсов.
   * Подсистема хранения данных.
   * Сетевая подсистема.
{/ifndef}

{ifdef(box)}
* Группа подсистем PaaS/SaaS:

   * Подсистема управляемых баз данных.
   * Подсистема управляемых контейнеров.
{/ifdef}

{ifdef(cer)}
* Подсистема управления доступом.
* Подсистема вычислительных ресурсов.
* Подсистема программно-определяемой сети.
* Подсистема хранения образов.
* Подсистема хранения данных.
* Подсистема резервного копирования.
* Подсистема управления квотами.
* Подсистема управления биллингом.
* Подсистема интерфейса пользователя.
* Подсистема интерфейса администратора.
{/ifdef}

## {heading(Требования к квалификации персонала)[id=personnel_qualification_requirements]}

Системные администраторы (Администраторы {var(sys2)}) отвечают за следующие аспекты:

* Комплексную настройку инфраструктуры {var(sys2)}, предоставляемой в качестве услуги конечным потребителям.
* Устранение неисправностей.
* Сбор диагностической информации.
* Эскалацию неисправностей производителю аппаратной или программной составляющей.

{ifdef(box)}

<warn>

При возникновении неисправностей в работе {var(sys2)} обращайтесь в {linkto(../technical_support#technical_support)[text=группу технической поддержки]}.

</warn>

{/ifdef}

В основные обязанности системных администраторов при работе с {var(sys5)} входит:

* Настройка и диагностирование {var(sys2)}.
* Обслуживание системного и прикладного программного обеспечения {var(sys2)}.
* Администрирование служебных баз данных {var(sys2)}.
* Резервное копирование и восстановление данных {var(sys2)}.
* Производство регламентных работ и анализ их результатов.

К системным администраторам предъявляются следующие требования:
<!--- // в ТЗ нет отдельных требований к сисадминам -- взято из 2.0 -->

* Знание архитектуры компонентов OpenStack и CEPH.
* Экспертные знания в эксплуатации операционных систем семейства Linux.
* Знание интерфейса командной строки Bash.
* Знание инструментов автоматизации Ansible.
* Умение программировать на алгоритмическом языке Python (опционально).
* Понимание принципов функционирования облачных и интернет-сервисов, их масштабирования, и построения отказоустойчивых систем.
* Опыт работы с программным обеспечением для автоматизации развёртывания и управления приложениями в средах с поддержкой контейнеризации Docker.
{ifdef(box)}
* Опыт работы с программным обеспечением для оркестрации контейнеризированных приложений Kubernetes.
{/ifdef}
* Понимание принципов работы сетевых протоколов: TCP/IP, DNS, HTTP, BGP (динамическая маршрутизация).
* Понимание принципов работы систем и протоколов хранения данных: FC, NFS, CEPH, S3.
