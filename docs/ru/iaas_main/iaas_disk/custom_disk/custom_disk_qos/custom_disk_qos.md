# {heading(Проверка дисков внешней СХД со спецификацией QoS)[id=custom_disk_qos]}

1. Перейдите в раздел **Облачные вычисления** → **Типы дисков**.

1. Найдите диск с внешней СХД, и в столбце **Привязанная спецификация QoS** скопируйте идентификатор спецификации QoS.

1. Проверьте настройку OpenStack CLI (подробнее — в разделе {linkto(../../../../interfaces_access#use_openstackcli_admin)[text=%text]}).

1. Выведите данные диска со спецификацией QoS. Для этого на управляющем узле с установленным OpenStack CLI выполните команду:
   
   ```console
   # openstack volume qos show <ID_QoS>
   ```
   Здесь `<ID_QoS>` — идентификатор спецификации QoS, скопированный на шаге 2.

1. Перейдите в Портал самообслуживания с учетными данными пользователя {var(sys2)}.

1. Проверьте, что в проекте достаточно ресурсов для создания ВМ с 1 диском.

1. Перейдите в раздел **Облачные вычисления** → **Виртуальные машины**.

1. Нажмите кнопку **Создать инстанс** или **Добавить**.

1. На странице **Создание нового инстанса** выберите:

   * **Тип виртуальной машины** — тип ВМ с количеством CPU не менее `1` и количеством ОЗУ не менее `1` ГБ.
   * **Тип диска** — `Внешний диск (СХД)`.
   * **Операционная система** — РЕД ОС.

1. Оставьте значения остальных полей без изменений и нажмите кнопку **Следующий шаг**.
1. Нажмите кнопку **Создать инстанс**.
1. Дождитесь завершения создания ВМ и откройте страницу **Виртуальные машины**.
1. Нажмите на имя созданной ВМ.
1. Откройте вкладку **Консоль** и выполните вход на ВМ.
1. В терминале ВМ выполните команду:

   ```console
   # fio --randrepeat=1 --ioengine=libaio --direct=1 --gtod_reduce=1 --name=fiotest --filename=testfio --bs=4k --iodepth=64 --size=1G --readwrite=randrw --rwmixread=50
   ```
   {caption(Пример вывода команды)[align=left;position=above]}
   ```console
   # Run status group 0 (all jobs): READ: bw=1999KiB/s (2047kB/s), 1999KiB/s-1999KiB/s (2047kB/s-2047kB/s), io=512MiB (537MB), run=262158-262158msec WRITE: bw=2000KiB/s (2048kB/s), 2000KiB/s-2000KiB/s (2048kB/s-2048kB/s), io=512MiB (537MB), run=262158-262158msec
   ```
   {/caption}
   
   В примере статистика по показателям операций в строке `Run status group` для значений `READ` и `WRITE` соответствует подключенной спецификации QoS.
