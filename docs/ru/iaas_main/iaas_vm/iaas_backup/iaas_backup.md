# {heading(Резервное копирование)[id=iaas_backup]}

Резервные копии ВМ и их дисков сохраняются в хранилище S3. Компонент Karboii выполняет оркестрацию резервных копий для ВМ и БД. Karboii ставит задачи на создание резервной копии в cinder-backup, который выполняет задачу и загружает резервную копию в S3 бакет, указанный в конфигурации.

Для успешного выполнения резервного копирования необходимо, чтобы образ имел следующие свойства:

```console
--property hw_qemu_guest_agent=yes --property os_require_quiesce=yes
```

Все операции по резервному копированию выполняются в Портале самообслуживания (подробнее — в документе **Руководство пользователя {ifdef(box, pg)}{var(system)}{/ifdef}{ifndef(box, pg)}{var(system_go)}{/ifndef}** в разделе **Облачные вычисления** → **Резервное копирование**).

Доступные операции:

* Создание резервной копии.
* Восстановление ВМ из резервной копии.
* Создание и редактирование плана резервного копирования (автоматическое резервное копирование).
* Ручное резервное копирование.
