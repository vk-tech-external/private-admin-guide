## {heading(Создание образа)[id=iaas_vm_images_create]}

Чтобы создать образ, используйте один из интерфейсов:

* Портал самообслуживания (подробнее — в документе **Руководство пользователя {ifdef(box, pg)}{var(sys)}{/ifdef}{ifndef(box, pg)}{var(sys_go)}{/ifndef}** в разделе **Облачные вычисления** → **Образы**).
* Портал администратора.
* OpenStack CLI.

Образ можно создать путем загрузки файла в формате `RAW` или создания из существующего диска.

<err>

Публичные образы ВМ, взятые вне {ifdef(box, pg)}{var(sys2)}{/ifdef}{ifndef(box, pg)}{var(sys2_go)}{/ifndef}, необходимо предварительно подготовить для загрузки в {ifdef(box, pg)}{var(sys4)}{/ifdef}{ifndef(box, pg)}{var(sys4_go)}{/ifndef} (подробнее — в разделе {linkto(../../../iaas_main/iaas_vm/images_preparation#images_preparation)[text=%text]}). Иначе может не работать часть функций, например, резервное копирование.

</err>

{ifndef(cer)}

### {heading(Портал администратора)[id=iaas_vm_images_creating]}

Чтобы создать образ из файла в Портале администратора:

1. Перейдите в раздел **Облачные вычисления** → **Образы**.
1. Нажмите кнопку **Добавить**. Задайте параметры образа:

   * Подробности образа:

      * **Имя образа** — название образа. Обязательный параметр.
      * **Описание образа** — краткое описание образа.
      * **Тип источника** — тип источника, из которого загружается образ.
      * **Формат** — формат загруженного файла образа.
      * **Файл** — файл образа.
      <!--- // про следующие два параметра нет достаточной информации в документации Openstack (нашла в настройках без объяснения https://docs.openstack.org/horizon/latest/configuration/settings.html) -->

   * Требования Образа:

      * **Ядро** — образ ядра.
      * **Диск в памяти** — образ диска RAM.
      * **Архитектура** — архитектура образа. Примеры: `i386` для 32-битной или `x86_64` для 64-битной архитектуры. 
      <!--- // в оф. документации прописано, что поля не заполняются https://docs.openstack.org/horizon/latest/user/manage-images.html -->
      * **Минимальный размер диска (ГБ)** — минимальный размер диска в ГБ. Оставить поле пустым.
      * **Минимальный размер памяти (МБ)** — минимальный размер RAM в МБ. Оставить поле пустым.

   * Общий доступ к образу:

      * Видимость:

         * **Публ.** — публичный (доступен всем проектам).
         * **Приватный** — приватный (доступен только в том проекте, в котором создан).

      * **Защищенный** — признак защищенности образа. В случае опции **Да** его смогут удалить только пользователи с соответствующими правами.

1. Нажмите кнопку **Создать образ** и дождитесь сообщения об успешном выполнении операции.
1. Вернитесь на страницу **Образы** и найдите в списке созданный образ.
1. Нажмите на значок справа от поля поиска и выберите вариант **Реальные данные** (по умолчанию показаны **Кешированные данные**).
1. Нажмите на значок **•••** справа от названия созданного образа и выберите пункт **Обновление метаданных**.
1. Нажмите кнопку **Редактировать**.
1. Добавьте пользовательские метаданные (пары **ключ** — **значения**), нажав кнопку **Добавить** для каждой пары значений:

   * `hw_qemu_guest_agent` — `yes`.
   * `hw_vif_multiqueue_enabled` — `true`.
   * `os_require_quiesce` — `yes`.
   * `os_type` — `linux`.

1. Нажмите кнопку **Сохранить изменения**.

<warn>

Максимальная длина каждого ключа и значения — 255 символов.

</warn>

### {heading(OpenStack CLI)[id=iaas_vm_images_creating_cli]}

Чтобы загрузить образ в OpenStack CLI:

1. Выполните подготовительные операции (подробнее — в разделе {linkto(../../../interfaces_access#use_openstackcli_admin)[text=%text]}).
1. Выполните команду:

   {include(../../../cli_commands/_includes/_cli_commands.md)[tags=cli_openstack_image_create_cmd]}

1. Если необходимо загрузить образ с поддержкой резервного копирования, добавьте свойства для работы с `qemu-guest-agent`:

   ```console
   # openstack image create --private --container-format bare --disk-format raw --file <ИМЯ_ФАЙЛА.raw> --property hw_qemu_guest_agent=yes --property os_require_quiesce=yes <ИМЯ_ОБРАЗА>
   ```

<info>

Полный список доступных команд приведен в [документации OpenStack](https://docs.openstack.org/glance/rocky/admin/useful-image-properties.html).

</info>

## {heading(Удаление образа)[id=iaas_vm_images_delete]}

Чтобы удалить образ, используйте один из интерфейсов:

* Портал самообслуживания (подробнее — в документе **Руководство пользователя {var(system)}** в разделе **Облачные вычисления** → **Образы** → **Портал самообслуживания** → **Удаление образа**).
* Портал администратора.
* OpenStack CLI.

<err>

Удаление образа, который используется в активной ВМ, может повлечь поломку пересчета биллинга.

</err>

### {heading(Портал администратора)[id=iaas_vm_images_delete_sa]}

Чтобы удалить один или несколько образов в Портале администратора:

1. Перейдите в раздел **Облачные вычисления** → **Образы**.
1. Нажмите на значок справа от поля поиска и выберите вариант **Реальные данные** (по умолчанию показаны **Кешированные данные**).
1. Установите флажки для образов, которые необходимо удалить.
1. Нажмите на значок удаления над таблицей и подтвердите удаление.

<info>

Удаление образов в Портале администратора не поддерживается, если:

* Образ создан на основе другого образа.
* Образ создан другим пользователем.
* Образ используется в одном из существующих (не обязательно включенных) инстансов.

</info>
