# {heading(Настройки firewall)[id=network_firewall_setup]}

Настройка firewall осуществляется с помощью управления группами безопасности (в Портале администратора раздел **Сетевая подсистема** → **SecGroupRulesPages**). Группы безопасности — это наборы правил IP-фильтрации, которые устанавливают права сетевого доступа и могут применяться к ВМ в проекте.

В целях безопасности на всех создаваемых машинах удалены пароли, а вход возможен только по протоколу SSH с авторизацией по RSA-ключам. Перед началом работы добавьте соответствующие правила и группу безопасности, чтобы разрешить пользователям доступ к ВМ по следующим протоколам:

* SSH — для подключения.
* ICMP — для выполнения проверок сетевой доступности командой `ping`.

<warn>

К каждой созданной ВМ по умолчанию добавляется группа **default**. Не добавляйте правила в эту группу. Данная группа безопасности разрешает весь исходящий и входящий трафик от других ВМ с этой группой безопасности.

</warn>

Настройка firewall осуществляется с помощью Портала самообслуживания (подробнее — в документе **Руководство пользователя {ifdef(box, pg)}{var(sys)}{/ifdef}{ifndef(box, pg)}{var(sys_go)}{/ifndef}** в разделе **Виртуальные сети** → **Настройки Firewall**).
