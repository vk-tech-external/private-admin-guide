# {heading(Управление сетями)[id=network_managed]}

## {heading(Просмотр)[id=network_managed_view]}

Чтобы ВМ видели друг друга в пределах одной сети/подсети, укажите сетевые настройки (принадлежность к сети/подсети) в каждой из ВМ.

Чтобы просмотреть список сетей, используйте один из интерфейсов:

* Портал самообслуживания (подробнее — в документе **Руководство пользователя {ifdef(box, pg)}{var(system)}{/ifdef}{ifndef(box, pg)}{var(system_go)}{/ifndef}** в разделе **Виртуальные сети** → **Сети** → **Управление сетями, подсетями и портами** → **Просмотр списка сетей**).
* Портал администратора.
* OpenStack CLI.

{ifndef(cer)}
### {heading(Портал администратора)[id=network_managed_view_sa]}

Чтобы просмотреть список сетей в Портале администратора перейдите в раздел **Сетевая подсистема** → **Сети**.

Чтобы просмотреть список сетей, доступных проекту или созданных в нем, введите в текстовом поле **Фильтр** один из параметров:

* **project_id** — UID проекта.
* **project_name** — название проекта.

* Портал администратора.

{ifndef(cer)}
#### {heading(Портал администратора)[id=subnet_creating_sa]}

Чтобы создать подсеть через Портал администратора:

1. Перейдите в раздел **Сетевая подсистема** → **Сети**.
1. Нажмите кнопку слева от текстового поля **Фильтр** и выберите вариант **Реальные данные** (по умолчанию показаны **Кешированные данные**).
1. Нажмите на имя сети.
1. Перейдите на вкладку **Подсети**.
1. Нажмите кнопку **Добавить**.
1. Задайте параметры подсети:

   * **Название подсети** — название подсети.
   * **Сетевой Адрес** — адреса сети в нотации CIDR.
   * **Версия IP** — версия IP подсети.
   * **IP шлюза** — IP шлюза для подсети (по умолчанию это первый IP-адрес сети).
   * **Запретить шлюз** — признак использования шлюза.
   * **Разрешить DHCP** — признак использования DHCP.
   * **Выделение пулов** — пулы IP-адресов, доступных для выдачи посредством DHCP; каждое значение на отдельной строке.
   * **Сервера DNS** — список IP-адресов имен DNS-серверов для этой подсети. Каждое значение на отдельной строке.
   * **Маршруты узла** — дополнительные маршруты для данной подсети. Каждое значение на отдельной строке.

1. Нажмите кнопку **Создать**.

   Созданная подсеть появится в общем списке подсетей для указанной сети.

### {heading(Создание портов)[id=port_creating]}

Чтобы создать порт, используйте один из интерфейсов:

* Портал самообслуживания (подробнее — в документе **Руководство пользователя {ifdef(box, pg)}{var(system)}{/ifdef}{ifndef(box, pg)}{var(system_go)}{/ifndef}** в разделе **Виртуальные сети** → **Сети** → **Создание сетей, подсетей и портов** → **Создание портов**).
* Портал администратора.

{ifndef(cer)}
#### {heading(Портал администратора)[id=port_creating_sa]}

Чтобы создать порт через Портал администратора:

1. Перейдите в раздел **Сетевая подсистема** → **Сети**.
1. Нажмите кнопку слева от текстового поля **Фильтр** и выберите вариант **Реальные данные** (по умолчанию показаны **Кешированные данные**).
1. Нажмите на имя сети.
1. Перейдите на вкладку **Порты**.
1. Нажмите кнопку **Добавить**. Задайте параметры порта:

   * Обязательные параметры:

      * **ID сети** — идентификатор сети, для которой создается порт. Заполняется автоматически.
      * **Имя** — название порта.
      * **Включить состояние администратора** — признак управления сетью.
      * **Укажите IP-адрес или подсеть** — связать IP-адрес или подсеть. В выпадающем списке выберите один из вариантов и заполните соответствующее поле с адресом.

   * Необязательные параметры:

      * **ID устройства** — ID устройства, подключенного к порту.
      * **Владелец устройства** — владелец устройства, подключенного к порту.

1. Нажмите кнопку **Сохранить изменения**.

<info>

Создание порта также доступно через раздел **Сетевая подсистема** → **Порты**. Нажмите кнопку **Добавить** и укажите сеть, для которой создается порт. Остальные параметры совпадают с описанными выше.

</info>
