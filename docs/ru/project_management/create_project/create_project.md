Чтобы создать проект:

1. В интерфейсе Портала администратора {ifdef(box, pg)}{var(sys2)}{/ifdef}{ifndef(box, pg)}{var(sys2_go)}{/ifndef} перейдите в раздел **Управление проектами** → **Проекты**.
1. Нажмите кнопку **Добавить**.
1. В окне **Создание проекта** введите название проекта и нажмите кнопку **Создать**.

Чтобы активировать сервисы в проекте:

1. В разделе **Управление проектами** → **Проекты** выберите проект из списка.
1. Перейдите на вкладку **Сервисы**.
1. Нажмите кнопку **Активировать все сервисы**.

Чтобы предоставить пользователю доступ к проекту в Портале самообслуживания, добавьте пользователя в группу и настройте доступ для группы (подробнее — в разделе {linkto(../../users_management/access#superadmin_project_access_settings)[text=%text]})
