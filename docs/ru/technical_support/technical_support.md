# {appendix-heading(Техническая поддержка)[id=technical_support; position=prefix]}

Если при работе с {var(sys5)} у вас возникли проблемы, которые не удалось решить самостоятельно, или если у вас появились дополнительные вопросы, свяжитесь с группой технической поддержки {var(sys2)} по одному из следующих каналов:

* Электронная почта: [privatecloud_support@corp.mail.ru](mailto:privatecloud_support@corp.mail.ru).
* Портал технической поддержки: [https://support.mcs.mail.ru](https://support.mcs.mail.ru).
* Чат-бот в Telegram: @vk_tech_support_bot.

В своём обращении детально опишите инцидент, предоставив следующую информацию (если применимо):

* Точные дата/время возникновения ошибки.
* Точная последовательность действий по воспроизведению ошибки, её описание с указанием аппаратного окружения, программного окружения и внешних систем.
* Журналы работы компонентов, протоколирующие работу системы во время сбоя.
* Информация о том, воспроизводится ли эта ошибка в другом окружении (да, нет или не проверяли).
* Любая дополнительная информация, которая может помочь в поиске ошибки (например, скриншоты).

<warn>

Техническую поддержку пользователей заказчика осуществляет сам заказчик. Поддержка администраторов {var(sys2)} осуществляется в соответствии с договором.

</warn>

В зависимости от заключённого договора выделяются два уровня технической поддержки:

* {linkto(#advanced_tech_support)[text=Расширенный]}.

## {appendix-heading(Базовая техническая поддержка)[id=basic_tech_support; position=prefix]}

В рамках базовой поддержки ПО {var(sys2)} обращения рассматриваются только после устранения неисправностей в инфраструктуре заказчика для выявления корневых причин проблем с программным кодом ПО. Консультации по функциональным возможностям {var(sys2)} предоставляются вне зависимости от приоритета обращения.

### {appendix-heading(Состав работ)[id=basic_tech_support_work_scope; position=prefix]}

В базовую поддержку входят следующие работы:

* Исправление ошибок в программном коде ПО или технической документации.
* Консультации по функциональным возможностям {var(sys2)}.
* Консультации по выявлению и устранению корневых причин инцидентов.
* Предоставление доступа к базе знаний.
* Предоставление доступа к актуальной документации и другим информационным материалам по настройке и работе ПО.
* Предоставление новых версий ПО.

При составлении заявки или в процессе выполнения работ по ней вы можете вносить предложения по реализации новых и модификации существующих функций {var(sys2)} (если группа технической поддержки подтвердила, что указанных функций действительно нет).

## {appendix-heading(Расширенная техническая поддержка)[id=advanced_tech_support; position=prefix]}

В рамках расширенной поддержки ПО {var(sys2)} рассматриваются обращения по неисправностям в инфраструктуре, вызванные наличием ошибки в коде ПО {var(sys2)}, а также оказываются консультации по функциональным возможностям {var(sys2)} (подробнее — в разделе {linkto(#advanced_scope)[text=%text]}).

### {appendix-heading(Состав работ)[id=advanced_scope; position=prefix]}

В рамках расширенной поддержки предоставляются следующие виды работ:

* Устранение нештатных ситуаций в работе {var(sys2)}.
* Разработка временных (обходных) решений для минимизации воздействия ошибок в программном коде ПО на работу {var(sys2)}.
* Предоставление рекомендаций для достижения оптимального функционирования {var(sys2)} в конкретных условиях заказчика.
* Выполнение административных операций по обслуживанию и эксплуатации {var(sys2)} в соответствии с сервисным каталогом.
