# {heading(Плавающие IP-адреса у ВМ)[id=iaas_floating_ip]}

Когда в сервисе Облачных вычислений запускается ВМ, ей автоматически назначается постоянный (статический) IP-адрес в сети. Он сохраняется до удаления ВМ.

Существуют назначаемые (плавающие) IP-адреса, которые можно привязать к ВМ. В отличие от статических, назначаемые IP-адреса могут менять привязку к ВМ в любой момент времени, вне зависимости от состояния самих ВМ. Это не «динамические» IP в привычном понимании: они не меняются самостоятельно.

Назначаемые IP-адреса закреплены за проектом, даже если отвязать IP-адрес от ВМ. Список закреплённых IP-адресов можно посмотреть в Портале самообслуживания в разделе **Сетевая подсистема** на странице **Плавающие IP**.

## {heading(Выделение плавающего IP-адреса для ВМ)[id=iaas_floating_ip_for_vm]}

Привязка плавающего IP-адреса (Floating IP) понадобится, если не был разрешён удалённый доступ к ВМ.

Инструкция по назначению плавающего IP для ВМ через Портал самообслуживания приведена в **Руководстве пользователя {var(system)}**.
