# {heading(Настройка приватной сети)[id=iaas_private_network]}

Для постоянной работы создайте свою приватную сеть и маршрутизатор, а затем запускать в них виртуальные машины. Это позволит полноценно использовать облачную инфраструктуру.

Создание приватной сети состоит из двух этапов:

1. Создание сети.
1. Создание маршрутизатора.

## {heading(Создание сети)[id=iaas_private_network_create_network]}

Создание приватной сети аналогично созданию обычной сети (подробнее — в разделе {linkto(../../../usage/iaas_main/iaas_network_settings#network_creating)[text=%text]}).

При создании сети одновременно создается подсеть — без этого невозможно привязать сеть к ВМ (подробнее — в разделе {linkto(../../../usage/iaas_main/iaas_network_settings#subnet_creating)[text=%text]}). В настройках подсети задайте параметры:

* **Сетевой адрес** — адресация и размер сети.

   Рекомендуемые значения для частной сети:

   * `10.0.0.0/24`.
   * `192.168.0.0/24`.
   * `172.16.0.0/24`.

* **Запретить шлюз** — установите флажок для отключения IP-адреса шлюза. Если шлюз отключен, назначить белый IP не получится и доступ в интернет будет закрыт.

## {heading(Создание маршрутизатора)[id=iaas_private_network_create_router]}

Шаги по созданию маршрутизатора описаны в разделе {linkto(../../../usage/iaas_main/iaas_network_settings#router_creating)[text=%text]}.

Чтобы подключить частную сеть к созданному маршрутизатору, в Портале самообслуживания выполните шаги, описанные в **Руководстве пользователя {var(system)}**. В диалоговом окне добавления интерфейса выберите созданную ранее подсеть.
