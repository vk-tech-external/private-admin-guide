# {heading(Создание проекта)[id=project_management]}

Чтобы создать проект:

1. В интерфейсе Портала администратора {var(sys2)} перейдите в раздел **Управление проектами** → **Проекты**.
1. Нажмите кнопку **Добавить**.
1. В окне **Создание проекта** введите название проекта и нажмите кнопку **Создать**.

Чтобы активировать сервисы в проекте:

1. В разделе **Управление проектами** → **Проекты** выберите проект из списка.
1. Перейдите на вкладку **Сервисы**.
1. Нажмите кнопку **Активировать все сервисы**.

Чтобы предоставить пользователю доступ к проекту в Портале самообслуживания, добавьте пользователя в группу и настройте доступ для группы (подробнее — в разделе {linkto(../../usage/users_management#superadmin_project_access_settings)[text=%text]})
