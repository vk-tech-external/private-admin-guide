# {appendix-heading(Агент)[id=xaas_vendor_ibimage_agent; position=prefix]}

Агент — это программное обеспечение, устанавливаемое на ВМ в процессе разворачивания сервиса. Основные функции:

* Выполняет скрипты.
* Контролирует выполнение скриптов.
* Позволяет использовать результаты выполнения скриптов при разворачивании инстанса сервиса.
* Позволяет отправлять результаты выполнения скриптов пользователю.
* Позволяет настроить мониторинг и автовосстановление ВМ инстанса сервиса (отслеживание состояния ВМ и повторное разворачивание ВМ, если она вышла из строя).

<warn>

Агент обязательно должен быть в образе сервиса, который разворачивается в кластере.

</warn>

В образе сервиса, который разворачивается на одной ВМ, агент может отсутствовать. В этом случае у сервиса не будет следующих возможностей:

* Контроля выполнения скриптов.
* Отправления результатов выполнения скриптов пользователю.
* Мониторинга.

Например, без агента не будет возможности передать одноразовый пароль для первичной настройки инстанса сервиса, сгенерированный скриптом.

Использование агента обеспечивается провайдером iVK CS (подробнее — в разделе {linkto(../../../../xaas_instructions/xaas_vendor_ibservice_add/xaas_vendor_tf_manifest/xaas_vendor_tf_manifest_steps#xaas_vendor_tf_manifest_steps)[text=%text]}).
