# {appendix-heading(Подготовительные операции)[id=xaas_vendor_ibservice_upload_prepare; position=prefix]}

У пользователя, загружающего сервисный пакет в Marketplace, должна быть учетная запись на {var(sys6)}.

Передайте администратору {var(sys2)} следующую информацию:

* Название компании.
* Идентификатор проекта (OpenStack PID), в котором будет выполняться тестирование манифестов Terraform.

   Значение отображается в Портале самообслуживания на странице настроек проекта на вкладке с Terraform.

* Электронную почту пользователя, которому необходим доступ в тестовые пространства имен Marketplace, чтобы тестировать сервис до публикации.
* Электронную почту пользователя, который будет назначен владельцем сервисного ключа.
* Электронную почту пользователя, которому необходим доступ в тестовые пространства имен Marketplace, чтобы тестировать сервис до публикации.
* Электронную почту пользователя, который будет назначен владельцем сервисного ключа.
* Электронную почту пользователя, которому будут приходить уведомления об ошибках при создании инстансов сервиса.

   В ответ администратор передаст сервисный ключ. Он содержит тестовые и открытые пространства имен Marketplace, в которых будет доступен сервис.

<warn>

OpenStack PID должен быть в списке проектов поставщиков, чтобы тестировать манифесты Terraform локально и с системой развертывания.

</warn>
