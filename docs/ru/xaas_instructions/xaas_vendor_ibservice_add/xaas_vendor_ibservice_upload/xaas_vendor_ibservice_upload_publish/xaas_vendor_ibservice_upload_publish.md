# {appendix-heading(Публикация сервиса)[id=xaas_vendor_ibservice_upload_publish; position=prefix]}

Потребителям сервис будет доступен только после публикации.

Чтобы опубликовать image-based приложение в Marketplace, сообщите администратору {var(sys2)} ID сервиса и его ревизию.

Будет проведено модерирование сервисного пакета. После этого сервис будет опубликован в Marketplace.

Публикуемая ревизия сервиса перемещается из тестового пространства имен Marketplace в открытое, указанное в сервисном ключе. Сервис будет доступен всем пользователям, имеющим доступ в это открытое пространство имен.

<warn>

В открытых пространствах имен доступна только последняя опубликованная ревизия сервиса.

</warn>
