# {appendix-heading(Публикация сервиса)[id=xaas_vendor_saas_upload_publish; position=prefix]}

Потребителям сервис будет доступен только после публикации.

Чтобы опубликовать SaaS-приложение в Marketplace, сообщите администратору {var(sys2)} ID сервиса и его ревизию.

Будет проведено модерирование конфигурации сервиса. После этого сервис будет опубликован в Marketplace.

Публикуемая ревизия сервиса перемещается из тестового пространства имен Marketplace в открытое, указанное в параметре `metadata` в конфигурации сервиса. Сервис будет доступен всем пользователям, имеющим доступ в это открытое пространство имен.

<warn>

В открытых пространствах имен доступна только последняя опубликованная ревизия сервиса.

</warn>
